# Recording Checklist

- Start the API with `python -m uvicorn api.main:app --reload`.
- Start the dashboard with `npm run dev`.
- Confirm the Predictive Analytics page reports model metadata.
- Use one realistic scenario and wait for its estimate.
- Show the held-out model comparison and limitations.
- Keep the recording between five and ten minutes.
- Do not state that model estimates guarantee actual delivery times.
- Confirm the final video, notebook, dashboard build, and documentation files before upload.
